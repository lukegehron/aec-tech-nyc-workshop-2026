# sample-data

Sample datasets the baseplates read. Fine to **add** a new file for your brick
here; don't delete existing ones other baseplates may depend on.

| File | What it is | Read by |
|---|---|---|
| `project.json` | **Navy Yard Commons** — a fictional Brooklyn mixed-use scheme: site, 3 buildings, 12 floors, 99 spaces, departments, materials. Every rollup agrees with the geometry. | 3D Viewer (through `lib/projectData.js`) |
| `floor-plan.svg` | A small floor plan in SVG | Vector Editor |
