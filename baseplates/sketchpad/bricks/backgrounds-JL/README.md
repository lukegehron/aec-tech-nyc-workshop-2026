# backgrounds-JL

Four background "brushes" for the Sketchpad: **Grid**, **Dot grid**,
**Isometric** and **Paper**. Pick one, click the canvas once to fill it, then
switch to any other brush and sketch over the background.

They use the existing controls: **colour** sets the line / dot / paper tint
colour, **size** sets the grid spacing (or paper grain). Laying a background
replaces what is on the canvas, so put it down first. **Clear** goes back to
white.

Ids end in `-JL`, so they start hidden. Turn them on from the
"Add to this surface" tray.
