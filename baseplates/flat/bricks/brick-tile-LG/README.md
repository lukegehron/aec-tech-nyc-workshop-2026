# brick-tile-LG

Luke Gehron's nametag: a playful 2×4 LEGO brick seen from above.

- **Top**: the title (`Agent Operator`) on a printed plate, above 2×4 studs. The first stud wears the GitHub portrait (`https://github.com/pwluke.png`); if it fails to load it shows the initials `LG`.
- **Side**: the name, printed on the side face of the brick.
- **Colour**: the toolkit. The brick takes the first tool colour, and every tool gets its own little tile underneath.

Card label is the name, card hint is the GitHub handle. React + Tailwind only. Edit the `USER` object at the top of `index.jsx` to change the person.
