# student-id-DY

A Magic: The Gathering style card for Dylan (DY): a hardhat-wearing
Creature — Spellcaster. Name in the title bar, toolkit as the mana cost,
Agent Operator in the type line, toolkit as the rules text, and the GitHub
handle as the artist credit.
Art comes from https://github.com/dylanbquan88.png and falls back to the
initials DY if it fails to load.
Everything lives in this folder; the baseplate is untouched.
