# luggage-SH

Sean's luggage tag brick for the Flat baseplate. Loop at the top, name,
title as the destination, toolkit as the airline, GitHub as the contact line.
Portrait comes from https://github.com/ummm-right.png, falling back to the
initials SH if it fails to load.

Registered in [`../bricks.js`](../bricks.js) with two lines.
