# Wallpaper

Choose a built-in pattern and enable **Wallpaper**. In **Massing** mode, click
one or more building faces to wallpaper them individually. You can also click a
flat surface mesh in an imported Rhino `.3dm` model. Patterns are projected in
world space at a consistent scale. Use **Clear** to restore the original
materials.

The tool only targets generated building faces in Massing mode and planar meshes
inside imported `.3dm` files; it leaves other viewer geometry and curved or
non-planar Rhino meshes alone.
